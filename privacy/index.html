隱私權政策

隱私權政策

最後更新：2026 年 10 月 15 日

本政策說明明仔載愛呷菜 Taiwan Market 如何在 iOS App、網站與 MCP 服務中處理資訊。發布者與營運者為 Thomas Braam。

摘要

  • App 不需要註冊帳號。
  • MCP 服務使用下方說明的假名化使用統計。本網站與 iOS App 不新增使用分析。
  • App 不使用第三方廣告、分析或追蹤 SDK。
  • App 不要求你的姓名、電子郵件、電話號碼、聯絡人、照片或精確位置。
  • 收藏項目、篩選條件、隱藏項目、快取市場資料與 App 設定會儲存在你的裝置上。

儲存在裝置上的資訊

App 會儲存購物體驗所需的本機資料，例如收藏項目、隱藏項目、顯示設定與已下載的市場資料。這些本機資料會透過 iOS 的 App 儲存 API，例如 SwiftData 與 UserDefaults 儲存。

市場資料下載

App 會下載公開蔬果與水產品市場資料檔案，用來顯示目前估價與歷史脈絡。這些下載用於提供 App 內容，不需要你提供身分資料。

MCP 請求處理

MCP 服務在 Cloudflare Workers 上運作，處理工具呼叫中的商品名稱與篩選條件，回傳公開蔬果、水產品估價或商品目錄。本服務不需要你的 ChatGPT 對話內容或帳號個人檔案。OpenAI 可能隨呼叫提供使用者識別碼；我們不要求你的姓名或電子郵件。

MCP 使用統計

我們使用 Cloudflare Workers Analytics Engine 了解使用情況、服務可靠性與商品關注度。對於通過驗證且啟用統計的工具呼叫，我們記錄工具、類別、成功或錯誤結果、回應耗時、查詢與配對數量、時間戳記，以及 OpenAI 提供的使用者識別碼（若有）。沒有有效識別碼的呼叫仍納入使用總數，並另行統計。

價格結果也會記錄每個不同商品的目錄標準 ID 與名稱，每次呼叫同一商品只記一次。此指標稱為「價格結果中的商品出現次數」：範圍較廣的搜尋可能包含數個商品。瀏覽商品目錄不計入此指標。

我們原樣保存提供的識別碼，不按月更換，以便計算不同識別碼的數量與跨日活動，不需要帳號個人檔案。這屬於假名化統計，並非完全匿名，識別碼數量也不等於經確認的實際人數。若識別碼超過 Cloudflare 的索引長度限制，僅抽樣索引使用固定雜湊值，保存的識別碼仍維持原樣。

我們的分析不記錄原始搜尋文字、對話內容、IP 位址、帳號個人檔案或其他用戶端中繼資料，也不保存 MCP 呼叫日誌或追蹤紀錄。Cloudflare 仍會為服務運作處理網路請求，並提供基礎設施彙總指標。分析中的回應耗時是實際經過時間，不是 CPU 使用時間。

停用 MCP 使用統計

你可以告訴 ChatGPT：「這次使用 Taiwan Market 時，請不要記錄使用統計。」所有工具都接受 record_usage: false，設定後該次呼叫不會產生我們的自訂統計，仍會正常回傳結果。如果涉及多次呼叫，請要求助理每次都設定此參數。省略參數時，預設會啟用統計。

此控制需要助理實際傳入參數，只適用於該次呼叫，不會移除先前紀錄，也不會停用 OpenAI 自身的處理或 Cloudflare 的基礎設施彙總指標。這項整合不會新增網站或 iOS App 分析。

資訊用途

本機 App 資料用來記住你的偏好與購物狀態。

分享

公開市場資料使用 Cloudflare 基礎設施託管。Cloudflare 也代表我們處理與保存 MCP 統計。本網站由 GitHub Pages 託管。OpenAI 會依其自身政策處理你的 ChatGPT 使用資訊。App 不會出售個人資訊。

保存與刪除

儲存在裝置上的資料可透過刪除 App 移除。

MCP 統計保存期限

Cloudflare Analytics Engine 保存事件三個月，之後自動到期。私人使用報表只顯示彙總資料，不列出個別識別碼。我們不會將提供的識別碼連結到你的 iOS App 資料。如有隱私權問題，請使用支援頁面。GitHub Issues 可能公開，請勿張貼識別碼或其他敏感資訊。

兒童

App 並非以 13 歲以下兒童為對象，也不會在知情情況下收集兒童的個人資訊。

變更

本政策可能會隨 App、網站或 MCP 服務調整而更新。頁面上方日期代表目前版本的發布日期。

聯絡方式

如有隱私權問題或支援需求，請使用 支援頁面。
